These are a few documents I created while working on the emulator. If you are trying to understand the Atari POKEY chip, you may find the following documents helpful. Start with the pokey.md and the Sound Half document. 

* pokey.md - Start here - Overview of the chip. 
* The Sound Half of POKEY.pdf - How the registers work and how the AUDF and AUDC registers are calculated. 
* pokey-pinout.svg - Pin-out diagram I created based on the original handwritten Atari documents. 
* pokey_reg_bit_field_reference.md - Summary of registers, bit-fields, meanings, and usages. 
* pokey_to_emulatormap.md - Looking at what a clean emulator could look like.
